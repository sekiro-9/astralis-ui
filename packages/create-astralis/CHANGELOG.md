# Changelog

All notable changes to `create-astralis`.

## 0.1.1 (2026-10-01)

- Uses astralis-cli 0.5.0, so new projects get the DevTools by default.
- Requires Node `^22.18` or `>=24.11`.
- Adds a README and an MIT LICENSE.

## 0.1.0 (2026-07-16)

The first release: `npm create astralis` runs `astralis create`, which
scaffolds a Next.js or Vite project with Astralis wired in.
