# Empty State

A placeholder for "no results", "nothing here yet" and recoverable-error
moments. Pure composition — the whole compound renders as a Server Component
and ships **zero client JavaScript**. Size travels to the parts via a data
attribute, not context.

## Import

```tsx
import { EmptyState } from "astralis-ui";
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Scales indicator, title and description together. |

### Parts

| Part | Renders | Notes |
| --- | --- | --- |
| `EmptyState.Indicator` | muted icon circle | `aria-hidden` — the icon is decorative. |
| `EmptyState.Title` | heading line | — |
| `EmptyState.Description` | supporting copy | Max-width capped for line length. |
| `EmptyState.Actions` | CTA row | Wraps; typically one or two Buttons. |
