# Context Menu

A [Menu](/docs/components/menu) opened by right-click and anchored at the
pointer instead of a trigger button. Everything else *is* Menu: the same
items, roving focus, typeahead, Escape/outside dismissal and styling.

<ComponentPreview name="context-menu-demo" />

## Import

```tsx
import { ContextMenu } from "astralis-ui";
```

## How it anchors

Right-clicking places an invisible 1px anchor at the pointer and opens the
menu against it. A right-click somewhere else first dismisses (outside
pointer-down), then reopens fresh at the new position, matching platform
context-menu behavior.

## Keyboard

The menu opens from the browser's `contextmenu` event, which the keyboard
fires too. For that to work the trigger element has to be focusable, as the
area in the demo above is.

| Key | Action |
| --- | --- |
| `Shift+F10` / `Menu` key | Open the menu from the focused trigger |
| `↑` `↓` | Move focus between items (wraps) |
| `Home` / `End` | First / last item |
| *type characters* | Jump to the item starting with what you typed |
| `Enter` / `Space` | Activate the focused item |
| `Esc` | Close |
| `Tab` | Close |
