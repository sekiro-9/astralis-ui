## Sizes

Thirteen steps from `xs` to `9xl`; the first eight cover almost all prose.

<ComponentPreview name="text-sizes" align="start" />

### Inheriting the size

`size="inherit"` takes the font size and line height of the parent, for a word
set apart inside a sentence. Without it a Text is `md`, whatever surrounds it.
It works per breakpoint too: `size={{ base: "lg", md: "inherit" }}`.

## Wrapping and figures

`textWrap` sets how lines break (`balance` for a short title, `pretty` for a
paragraph), `whiteSpace` keeps text on one line or keeps its own line breaks,
and `numeric="tabular"` lines figures up in a column. Heading and Link take
them too, and `whiteSpace` also works on Box and the layout primitives.

<ComponentPreview name="text-wrapping" align="start" />

## Hover and focus

`hover`, `focusVisible` and `active` take the same tokens as the base props, so
a colour change on hover needs no wrapper. They carry `color` and the
placement props; Heading and Link take them too.

<ComponentPreview name="text-states" align="start" />

## Responsive

Every prop on this page accepts a breakpoint map:

```tsx
<Text size={{ base: "sm", md: "md", lg: "lg" }} align={{ base: "center", md: "left" }}>
  Scales with the viewport
</Text>
```
