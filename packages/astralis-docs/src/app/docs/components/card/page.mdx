# Card

A content container with header, body and footer sections in four variants.

<ComponentPreview name="card-demo" />

## Import

```tsx
import { Card } from "astralis-ui";
// Card.Header, .Title, .Description, .Body, .Footer
```

## Anatomy

`Card.Header` takes an `extra` slot for trailing content (badges, menus);
`size` on the root scales every section's padding: the root stamps it as a
`data-card-size` attribute and the sections' CSS reads it, so the whole
compound stays a Server Component.

## Variants

`hoverable` lifts the card 4px with a deeper shadow on hover (the bordered
variants also firm up their border), and presses it in on click. Pair it with
clickable cards. With reduced motion the card stays put and only the shadow
and border change.

## Props

<PropsTable of="Card" rows={cardProps} />

Card and each of its parts take placement props only (see the last row), no
padding or paint: the card's look comes from `variant` and `size`. A body that
fills the card is `<Card.Body flex="1">`, and `display` hides a part below a
breakpoint; layout inside a part (`gap`, `alignItems`) is a `Stack` inside it.
A `Grid` with `alignItems="stretch"` already gives a row of cards equal
heights, and padding or a background goes on a wrapping `Box`.

`Card.Header` additionally takes `extra: ReactNode`; `Card.Title` renders an
`h3` and `Card.Description` a `p`. Both accept their native attributes.
