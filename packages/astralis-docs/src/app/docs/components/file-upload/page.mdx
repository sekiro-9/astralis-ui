# File Upload

File picking and drag-and-drop built around a hidden native
`<input type="file">` — the picker dialog, `accept` filtering and mobile
integrations stay the platform's. `maxSize`/`maxFiles` violations are
**rejected and reported** via `onReject`, never silently truncated.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Move to the dropzone, then to each file's remove button |
| `Enter` / `Space` on the dropzone | Open the file picker |
| `Enter` / `Space` on a remove button | Remove that file |

Dragging files is pointer-only; the picker is the keyboard path to the same
result.
