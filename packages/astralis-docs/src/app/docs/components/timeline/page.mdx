# Timeline

A vertical sequence of events with indicators, connectors and per-item colors.

<ComponentPreview name="timeline-demo" />

## Import

```tsx
import { Timeline } from "astralis-ui";
// Timeline.Item, .Indicator, .Content, .Title, .Description
```

## Usage

Indicators take anything — numbers, icons, or nothing (a plain dot) — and
`colorScheme` on an individual indicator overrides the root's, which is how
the completed step above turns green.
