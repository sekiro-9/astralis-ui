## Accessibility

- Renders `role="progressbar"` with `aria-valuemin/max/now` and a percentage
  `aria-valuetext`; indeterminate mode omits `aria-valuenow`, which is the
  standard ARIA signal for "busy, duration unknown".
- Give each bar an accessible name (`aria-label="Uploading photos"`) when
  more than one is on screen.
