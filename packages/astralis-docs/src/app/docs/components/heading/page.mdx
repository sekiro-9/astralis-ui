# Heading

Semantic headings built on [Text](/docs/components/text), with per-level size and weight defaults.

<ComponentPreview name="heading-demo" align="start" />

## Import

```tsx
import { Heading } from "astralis-ui";
```

## Usage

`as` picks the heading level (`h1`–`h6`, default `h2`) and brings a matching
default size (`4xl` → `md`) and weight (bold for h1–h3, semibold below).
Heading also presets the `heading` font family, tight leading and tight
tracking. Override any of it with the regular Text props.

## Decoupling size from level

Heading levels are for the document outline; size is for the design. Override
`size` freely without breaking semantics or accessibility.

<ComponentPreview name="heading-size-override" align="start" />

## Line height

Heading sets lines close together (`lineHeight="tight"`, 1.25), which suits
large display titles. `lineHeight="size"` uses the line height that comes with
the size instead: looser at the small sizes (1.4 at `xl`), about as tight at
the display sizes, and the parent's at `md`, which has none of its own.

<ComponentPreview name="heading-line-height" align="start" />

`"size"` is a whole value, not a breakpoint value: after another line height
at a smaller breakpoint it could not restore the size's own, so the types
reject `lineHeight={{ base: "tight", md: "size" }}`. A breakpoint map of other
line heights works as on Text, and replaces the tight default entirely.
